# UI-Standards

LeipzigerFlow verwendet die native Windows-Darstellung. Globale Qt-Stylesheets werden vermieden.

## Stammdaten-Dialoge

Oben befinden sich Titel und Sofortsuche. Darunter folgt eine kompakte Tabelle.

Button-Reihenfolge:

```text
Neu | Bearbeiten | Löschen                         Schließen
```

## Tastaturbedienung

- `Strg+N`: neuer Datensatz
- `Strg+F`: Suchfeld fokussieren
- `Enter`: ausgewählten Datensatz bearbeiten
- `Entf`: ausgewählten Datensatz löschen
- `Esc`: Dialog schließen
- Doppelklick auf eine Tabellenzeile: bearbeiten

## Tabellen

- nur entscheidungsrelevante Spalten anzeigen
- Sortierung unterstützen
- Auswahl immer zeilenweise
- Details gehören in den Bearbeitungsdialog
