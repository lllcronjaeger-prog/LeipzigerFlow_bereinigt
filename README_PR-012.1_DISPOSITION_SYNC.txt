PR-012.1 – Dispositions-Synchronisation

- Import aus Dispoplan XLS/XLSX
- wiederholbar mehrmals täglich
- Standorte werden aus Belade- und Entladeadresse angelegt/aktualisiert
- Transportaufträge werden anhand der Transportnummer angelegt/aktualisiert
- Stornos werden erkannt
- bereits verplante Aufträge werden anhand des Fahrzeugfeldes zu Touren zusammengefasst
- Fahrer und eigene Zugmaschinen werden zugeordnet, sofern sie im Stamm gefunden werden
- Menü: Import / Export -> Disposition synchronisieren
