LeipzigerFlow S1.5 PR-011.2.1 – Fenstergröße Fahrzeugbereich

Behoben:
- Die Zugmaschinenverwaltung öffnet beim ersten Start mit einer gut nutzbaren Standardgröße.
- Größe und Position des verwalteten Fahrzeugfensters werden zuverlässig gespeichert.
- Die Tabellenbreiten der Zugmaschinenverwaltung bleiben erhalten.
- Das Fenster „Zugmaschine bearbeiten“ speichert Größe und Position.
- Der Fahrzeug-Excel-Import speichert Größe, Position und Tabellenbreiten.
- Gespeicherte Fenster außerhalb sichtbarer Monitore werden auf den Hauptbildschirm zurückgeholt.
- QSettings wird beim Schließen unmittelbar synchronisiert.
